# gabut ah
selamat datang di Gabut ah !
gabut ah adalah aplikasi hiburan ringan yang membantu pengguna menghilangkan rasa bosan melalui konten menarik seperti fun fact, kius, rekomendasi acak, dan berbagai fitur interaktif lainnya. aplikasi ini di rancang agar bisa terus berkembang dengan menghadirkan konten baru dan pengalaman yang menyenangkan bagi pengguna dari kalangan 12-45 tahun
